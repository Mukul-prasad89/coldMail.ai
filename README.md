## 🚀 What Problem Does It Solve?

For IT consulting and staffing companies, identifying relevant hiring opportunities and preparing personalized outreach can be a time-consuming manual process.

Teams often need to:

1. Visit hiring or career pages manually.
2. Understand job roles and technical requirements.
3. Search their internal talent pool for relevant skills.
4. Identify suitable portfolio or candidate information.
5. Write personalized outreach emails.

**ColdMail.ai automates this workflow using LLMs, semantic search, vector databases, and full-stack technologies.**

---

## ✨ Key Features

- 🔗 **Job URL Input** — Provide a public hiring/career-page URL.
- 🕸️ **Web Content Extraction** — Retrieves and processes webpage content.
- 🧠 **LLM-Powered Job Extraction** — Extracts job role, experience, skills, and description.
- 📋 **Structured Output** — Converts unstructured job descriptions into structured JSON.
- 🔎 **Semantic Search** — Finds relevant talent based on semantic similarity rather than only exact keywords.
- 🗄️ **Vector Database** — Uses ChromaDB for similarity-based retrieval.
- ✍️ **Personalized Cold Emails** — Generates outreach based on job requirements and relevant portfolio information.
- ⚡ **End-to-End Workflow** — Connects the frontend, backend, LLM processing, vector search, and email generation into a single application.
